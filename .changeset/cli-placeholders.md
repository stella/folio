`folio placeholders` (MCP `placeholders`) lists the placeholders left in every story (`[•]`, `[…]`, `{{name}}`, `[[name]]`, `TODO`, or `--pattern`s) with block ids and context, fills them from `--fill` values as tracked changes or with `--direct`, and exits with the new code 11 while any remain. JSON flags also read `@file.json`.
