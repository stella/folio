List commands continue the list directly above or below the paragraph and otherwise start a new list at 1 (on an instance of that kind the package defines and nothing uses yet, when there is one); numbering a paragraph style supplies (numbered headings) is never joined. New `restartNumbering`, `continueNumbering` and `setNumberingValue(value)` commands, offered in the React and Vue context menus for a list item (with a Set Numbering Value dialog). AI edit operations accept `numbering: { start: "new", kind: "numbered" | "bullet", level? }` to start a new list.
