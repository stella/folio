Add `@stll/folio-cli`, the `folio` command line over the folio-agents tools for `.docx` files on disk. This release reads: `read`, `outline`, `section`, `stories`, `story`, `find`, `comments`, and `changes`, with flags generated from each tool's schema, a `{ ok, data | error }` envelope, SHA-256 `fileVersion` preconditions, labelled synthetic block ids, and version-bound read cursors.
