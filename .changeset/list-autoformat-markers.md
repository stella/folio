List autoformat recognises the common marker family at the start of a paragraph: `1.`, `1)`, `a.`, `a)`, `A.`, `i.`, `I.` (and `- `, `* `). The punctuation sets the level text, the letter case and numeral system the number format, and a typed value such as `3. ` starts the list at that value; a marker that matches the list directly above continues it. Four-digit numbers, zero, and words spelled in roman digits stay text.
