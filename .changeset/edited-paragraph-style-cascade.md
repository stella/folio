Paragraphs created by a paste, a cut, a table command or a replacement across paragraphs now show their inherited spacing, run defaults and table-style formatting immediately instead of only after the document is reopened. List commands, restyling, clearing a style and unindenting now leave the indentation and numbering a reopen reads, and a run that turns a heading's bold off reads as not bold.
