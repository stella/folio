`folio lang` (MCP `proofing_language`) reports the `w:lang` languages each part states and, with `--set`, writes a proofing language into the `w:docDefaults` run properties, the default paragraph style, every stated style language, and `w:themeFontLang`; `--runs` also sets every language a run states.
