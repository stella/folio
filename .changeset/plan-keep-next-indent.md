A template plan can keep a placed paragraph with the one after it (`keepNext`) and give it an indent of its own (`indent`), on a source item and on a nested paragraph. This is for a line that heads what follows in a style that does not keep it there, and for a number written as text that should hang the way the list's number would. Verification holds the output to both, with the new issue code `paragraph-format-mismatch`.
